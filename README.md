# 채용공고 기반 IT 직무 역량 분석 RAG 챗봇

점핏(Jumpit) 개발자 채용공고를 근거로 직무별 요구 역량을 답하고, 내 이력서와 비교해 부족한 역량을 알려주는 RAG 챗봇입니다.

## 문서
- [프로젝트 제안서](docs/proposal.pdf)
- [평가셋 (34문항)](eval/eval_set.xlsx)

## 문제 정의

- 공고마다 요구 기술·자격요건·우대사항이 달라 무엇부터 준비해야 할지 판단하기 어렵습니다.
- 여러 공고를 직접 찾아 읽고 비교하는 데 시간이 많이 듭니다.
- 일반 AI는 실제 공고가 아닌 일반론으로 답하거나, 마감일을 틀리고 공고에 없는 내용을 지어내기도 합니다.
  (ChatGPT 웹 검색 사용 시 5문항 중 4문항에서 마감일 오류·마감 공고 추천 확인 → 제안서 2-1)

## 타겟

취업·이직을 준비하는 신입~3년차 주니어 개발자

## 핵심 기능

| 기능 | 설명 | 단계 |
|---|---|---|
| 직무·경력별 공고 검색 | 직무·경력 조건으로 공고 필터링 | MVP |
| 채용공고 기반 Q&A | 수집된 공고를 근거로 요구 역량·우대사항·전형 절차 질의응답 | MVP |
| 특정 공고 상세 분석 | 선택한 공고 하나의 범위 안에서만 답변 | MVP |
| 근거 기반 답변 | 답변마다 출처 공고·항목과 마감 여부 표시, 공고에 없는 내용은 "확인되지 않습니다" | MVP |
| 이력서 기반 역량 분석 | 이력서와 공고 요구 역량을 비교해 부족한 역량 제시 | 확장 |

## 처리 흐름

1. 점핏 개발 직군 공고 수집 (신입~경력 3년 이하)
2. 데이터 정제 및 기술명 정규화 (예: 스프링 → Spring)
3. 항목 단위 Chunking + 메타데이터 부여 (직무·경력·기업·공고ID·마감일·수집일·기술스택)
4. Embedding → ChromaDB 저장
5. 질문 시 메타데이터 필터로 검색 범위 제한 (전체 / 직무·경력 필터 / 특정 공고)
6. 검색된 공고만 근거로 LLM 답변 생성
7. 인용한 근거 문장이 원문에 실제로 있는지 검증 후 답변 + 출처 + 마감 여부 제공

## 기술 스택

- Language: Python
- Vector DB: ChromaDB
- Embedding / LLM: 선정 예정

## 평가

- 평가셋 34문항: 질문 + 정답 + 근거 위치(공고ID / 항목) → [eval/eval_set.xlsx](eval/eval_set.xlsx)
- 질문 유형: 회사명 포함 사실 확인, 공고 선택 후 질문, 조건으로 찾기, 비교·종합, 답변 불가, 최신성(마감 여부), 표기 차이
- 지표 우선순위: 최신성 정확도 > 출처 정확도 > 답변 정확도 > 검색 정확도

## 데이터 출처 및 이용

- 출처: [점핏](https://jumpit.saramin.co.kr) 개발자 채용공고
- 현재 데이터: 2026-09-30 수집, 사용 문서 101건 (자세한 내용은 [데이터 카드](data/README.md))
- robots.txt상 공고 목록·상세 페이지는 수집 제한 경로가 아닙니다 (2026.09.29 확인).
- 사람인 회원약관 제19조에 따라 비상업 학습 목적으로만 사용하며, 공고 원문은 저장소에 공개하지 않습니다.

## 실행 방법

Python 3.13 기준입니다.

```bash
# 1. 가상환경 만들기 및 활성화 (Windows)
python -m venv .venv
.venv\Scripts\activate

# 2. 패키지 설치
pip install -r requirements.txt

# 3. 점핏 공고 수집 (다시 실행하면 새 공고 추가·변경 반영·마감 처리)
python src/collect_jumpit.py
```

수집 결과는 `data/postings.csv`, `data/collection_summary.csv`, `data/raw/`에 저장됩니다. 챗봇 실행 방법은 개발 후 추가할 예정입니다.
