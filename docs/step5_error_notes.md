## 4. 개선 방향 연결

중간점검 7-2의 사례와 강사님 피드백(개선 4가지)의 연결

| 중간점검 7-2 사례 | 문항 | 개선 방향 (강사님 피드백) |
|---|---|---|
| 사례 1. 공고 하나 안에서도 못 찾음 (학교종이 "전형 어떻게 돼?") | A10, T03 | 1. 공고를 선택하면 그 공고 전체를 근거로 넣기 |
| 사례 2. 여러 공고를 모아야 하는 질문 ("4년제 졸업 안 해도 되는 곳") | A11, A20 (보조 A14) | 3. 조건 찾기는 검색 말고 코드로: 학력·근무지·재택·기술스택을 공고마다 정해진 칸으로 뽑고, 코드로 거른 뒤 LLM은 설명만 |
| 사례 3. 한글로 쓴 기술 이름 ("스프링") | T01 | 2. 기술 동의어 사전 (제안서에 계획했지만 아직 만들지 않았음) |

단계마다 이전 단계를 켠 채로 새 기능을 하나 추가해 다시 측정하고 직전 단계와 비교한다. 공통 조건은 전략 B, top-5, gpt-6-luna, 채점 기준 v2다.

## 한계와 주의

- 문항이 정답이 있는 25개뿐이라 한 문항이 답변 정확도를 2~4%p 움직인다. 유형별 건수는 경향으로만 읽는다.
- 1차 기준선 판정은 LLM 채점이다. 같은 답변을 두 번 채점해도 판정이 바뀔 수 있다.
- 중간점검 7-1의 분류를 기준으로 하고, 이 문서에서 더한 것은 점수 손실, 청크 대조 확인(A03·A04·A09는 필요한 청크가 실제로 검색됐음), 유형 4가지로의 변환, "추가 관찰"이다. "추가 관찰"(A16의 직무 분류 혼입, A04·A05의 질문 모호)은 작성자의 판단이라 검수가 필요하다.
